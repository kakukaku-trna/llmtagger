“请分析输入视频片段，判断其中是否出现左转待转区场景
“你必须根据以下严格标准对视频进行分析。”
步骤1：寻找视频片段中包含道路交叉口（路口）的部分，“左转待转区”只会出现在路口，非路口区域的视频片段无须关注，如果整段视频都没有路口，则直接判否。
步骤2：检查包含路口视频片段内的关键视觉特征
1. 路口是否包含红绿灯，若路口没有红绿灯，则不会有待转区，这段数据同样可以忽略；
2. 路口对面是否有LED屏显示带有“左转待转区”字样，若有，则直接判是；
3. 确定当前行车方向上哪些车道是左转车道（包括左转兼直行车道），可以基于车道内指向箭头或者道路上方的指示牌及车道空间排布判定，需要注意左侧车道并非一定是左转车道；观察左转车道向前越过斑马线的区域，检查是否有短虚线引导线，若没有，则判直接否；若有两根短虚线一左一右，从左转车道的方向向前/左前方向延伸，短虚线之间存在左转箭头，短虚线最终被停止线截断，则判是；需要额外注意的是，可能会由于车辆遮挡，有可能只能观察到一侧的短虚线引导线，这时若观察到直行绿灯，左转红灯，车辆停在斑马线前方虚线引导线内，则也判是；
4. 关于第3点的补充说明，路口区域视频片段内，左转车道在斑马线前方区域是否出现“短虚线引导线”，“左转箭头”，“停止线”等关键要素，需要仔细辨别，由于路面标线磨损，视频运动模糊，夜间对比度低，视角变换等因素，难以确定结论时，尝试基于计算机视觉的方法处理素材，辅助辨认；
5. 关于第3点的补充说明,若短虚线之间不是左转箭头，而是“左转待转区”之类的文字标识，也判是
6. 关于第3点的补充说明,若在发现左转车道在斑马线前方区域有短虚线时，无法再同时在路口内确认“左转箭头/文字”和“停止线”两个特征，仅能确认一个特征时，也可以考虑判是，需要综合考虑；
7. 关于第3点和第6点的补充说明，若仅能发现短虚线，且短虚线一直延伸到通过路口的，则说明是导流线，不是待转区，应该判否；
步骤3：明确输出要求
- **严格使用 JSON 格式**: 最终输出必须是纯净的 JSON 对象，禁止包含任何 Markdown 标记。
- **字段说明**:
  - `result`: 明确判断"是"或"否"。
  - `reason`: 提供详细的推理过程，说明你是如何根据视频内容和场景定义得出结论的。

json 格式如下：
{
    "result": "是",
    "reason": "视频显示自车接近十字路口，在斑马线/人行横道的前方有短虚线，有左转箭头，有停止线，形成左转待转区的边界结构，判定场景成立。"
}
