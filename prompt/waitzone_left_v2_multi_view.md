# 2. 核心场景定义：【左转待转区的判断】

## 场景定义

本任务中的"左转待转区"的核心结构特征是：在人行横道/斑马线的前方存在一条停止线，并通过短虚线引导线与**左转车道**相连，形成供左转车辆使用的等待区域。

1. **位置特征**
   - 位于交叉口（十字路口或丁字路口）内部：**斑马线和前方红绿灯之间的区域**
   - 短虚线引导线和路口内停止线相比于斑马线离自车相机更远，这是位于路口内部的另一种描述

2. **标线结构特征**
   - **斑马线前方的左转箭头**：左转箭头，箭头往左转，方向垂直短虚线引导线，出现在斑马线前方则说明有极大可能是左转待转区
   - **停止线**：白色实线，这根线在观察视角不一定是横着的，但一定截断并封闭了左转车道短虚线
   - **短虚线引导线**：两根短虚线一左一右，从左转车道的方向（一般从斑马线对齐左转车道的位置）向前延伸，连接到路口内的停止线，实线长度和间隔长度都较短，视觉上会更“密”，
   - 路口内停止线+短虚线引导线共同构成左转待转区的物理边界

3. **视觉特征**
   - 左转待转区位于左转车道前方，延伸至交叉口内部
   - 可能有"左转弯待转区"等文字标识（非必须）
   - 可能有交通指示牌辅助说明

4. **排除场景（若满足以下特征则判定为"否"）**
   - 仅有路口导流线，同样是短虚线，用于引导车辆行驶方向，**无停止线**，**无指向箭头**，无区域边界，贯穿整个路口，这种情况不是左转待转区
   - 左转车道线到斑马线终止，路口内部无短虚线，左转箭头和停止线

# 3. 思考与分析步骤 (Chain of Thought)

1. **路口识别**
   - 观察数据是否出现交叉口（十字路口或丁字路口），重点分析可以观察到路口前和路口内的数据，建议基于**右上（front120）**分析是否是路口
   - 寻找人行横道/斑马线位置作为参照，选取斑马线和前方红绿灯之间的区域（路口区域）分析,**斑马线有可能直接出现在视频开头，不要忽略**，若前方没有发现斑马线，可以重点再检查**左下（rear70）**的画面，车辆可能已经进入路口，所以斑马线在后方
   - **时序分割规则**：跨越前仅记录车道导向箭头，车道；跨越后立即切换扫描目标为“路口内部区域”，此时朝前相机画面中所有新出现的路面标线均默认位于“斑马线前方”，直接纳入待转区特征核查。到通过路口后，所有特征就不属于路口了；进入路口后，**左下（rear70）**相机画面中出现的特征可以用于待转区特征复核，交叉验证
   - 检查路口的红绿灯，需要有左转红绿灯；检查LED屏，若屏幕上出现“左转待转区”字样，则说明存在待转区，这两个要素通常在路口对面，相距较远，建议基于**左上（front30）**画面检查

2. **标线结构识别（核心步骤）**
   - 检查在**斑马线/人行横道的前方**是否存在**左转箭头**
   - 检查是否有**短虚线**从左转车道向前延伸，连接到该路口内停止线，形成区域边界
   - 检查在**斑马线/人行横道的前方**是否存在**停止线**
   - 检查左转车道内是否有文字标识“待转区”/“左转待转区”
   - **视频长度有限，可能只拍到路口内的停止线和短虚线引导线部分，这是足够的判定依据**

3. **排除干扰项**
   - 仅有路口导流线，同样是短虚线，用于引导车辆行驶方向，**无停止线**，**无指向箭头**，无区域边界，贯穿整个路口，这种情况不是左转待转区
   - 排除普通的虚线车道线的干扰
   - 若没有单独的左转红绿灯，则可以直接判否
   - **重点注意**左转车道不一定出现在最左侧，需要严格基于指向箭头判断车道方向；若左侧是直行车道有待行区的情况，也需要判否

4. **综合判断**
   - 与当前信号灯颜色、车辆是否停车等待无关，不能只基于车辆路线和信号灯颜色判断
   - 当路口左转车道存在**左转箭头（位于斑马线前方）+ 短虚线引导线**的标线结构时，判定为"是"
   - 当路口左转车道存在**停止线（位于斑马线前方）+ 短虚线引导线**的标线结构时，判定为"是"
   - 左转车道内直接文字标注了“待行区”/“左转待转区”，则也可作为关键判据，输出“是”
   - 若无明确视觉证据，不得依据经验推断存在待转区。
