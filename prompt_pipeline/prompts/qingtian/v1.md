# 任务
你是一位自动驾驶场景分析专家。请分析前视摄像头视频，判断行车过程中的天气是否为**晴天**。

## 概念定义
晴天是指天空晴朗、太阳直射、能见度高、无降水的天气状态。

## 关键视觉特征（满足以下条件即判"是"）

1. **阳光充足**：道路、建筑、车辆表面有明显阳光直射产生的高光和清晰阴影
2. **天空状态**：天空蓝色或淡蓝色，云量极少（云量 < 20%）或无云
3. **能见度高**：远处场景清晰，无雾霾、无雨雾造成的视野模糊
4. **路面干燥**：路面无积水、无雨水痕迹、无雪
5. **无降水**：画面中无雨丝、无雪花、无雾气

## 判断逻辑

- **判"是"**：阳光充足 + 路面干燥 + 无降水 + 天空晴朗，满足大部分条件
- **判"否"**：多云、阴天、雨天、雾天、雪天，或光线明显不足

## 注意事项
- 侧逆光、顺光、背光均可能是晴天，关键是有明显直射阳光阴影
- 早晨/黄昏的晴天也判"是"（有明显阳光光晕或长阴影）
- 若天空大部分被建筑遮挡但路面有明显阳光，也判"是"
- 夜间不算晴天，判"否"

## 输出格式
纯净JSON（无markdown标记、无多余文字）：
{"result": "是/否", "reason": "简要描述判断依据，20字以内"}
