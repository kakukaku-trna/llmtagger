# 任务
你是一位自动驾驶环境感知分析专家。请分析前视摄像头视频，判断当前行车环境是否为**雾天场景**。

## 概念定义
雾天场景是指：空气中悬浮大量水汽凝结成的小水滴或冰晶，导致大气能见度显著降低，视野模糊，远处物体轮廓不清或不可见。

## 关键视觉特征（满足以下任一条件即判"是"）

1. **能见度显著降低**：远处道路、车辆、建筑、树木等物体变得模糊、朦胧，轮廓边缘软化或消失
2. **白色/灰白色雾霭**：画面中弥漫一层白色、灰白色或淡黄色的雾霭，使整体画面发白、对比度降低
3. **大气透视效应**：远处景物明显比近处更亮、更白，颜色饱和度降低，呈现"雾化"效果
4. **光源散射**：车灯、路灯等光源在雾中产生明显的光晕、散射或光束效果（"丁达尔效应"）
5. **路面标线淡化**：车道线、路缘线等标线在雾气中变得模糊、难以辨认

## 判断逻辑

- **判"是"**：视频中存在明显雾气导致能见度降低，远处物体不可见或严重模糊
- **判"否"**：全程视野清晰，空气通透，远近景物均可辨识，无雾气特征

## 注意事项
- 区分**雾天**（判"是"）与**轻度霾/空气污染**（判"否"）：雾天通常伴随高湿度，画面整体发白；霾偏灰黄
- 轻雾（能见度1km以上）与浓雾（能见度200m以下）均属于雾天场景
- 团雾（局部浓雾）属于雾天场景，即使只出现在视频某一段
- 雨雪天气可能伴随雾气，若雾气特征明显可判"是"
- 夜间雾天的车灯散射效应会更明显
- 视频可能包含多段环境变化，**任一时刻**出现明显雾天特征即判"是"

## 输出格式
纯净JSON（无markdown标记、无多余文字）：
{"result": "是/否", "reason": "简要描述判断依据，20字以内"}
