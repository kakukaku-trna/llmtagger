# 任务
你是一位自动驾驶场景分析专家。请分析前视摄像头视频，判断行车过程中是否存在**强反射/白天逆光**情况。

## 概念定义
强反射/白天逆光是指白天行车时，强烈阳光从车辆正前方或斜前方照射，导致摄像头曝光过度、画面局部或大面积过亮，严重影响前方道路和障碍物的视认。

## 关键视觉特征（满足以下任一条件即判"是"）

1. **镜头眩光**：画面中有明显太阳直射产生的镜头眩光（光晕、光斑、射线状光芒）
2. **画面过曝**：前方大面积区域过度曝光发白，道路细节丢失
3. **剪影效果**：前方车辆、行人或路牌呈黑色剪影，背景极亮
4. **路面强反射**：路面因积水或特殊材质产生镜面反射，路况难以辨认
5. **逆光天际线**：太阳位于行进方向正前方低位，视野内出现强烈光幕

## 判断逻辑

- **判"是"**：满足任意一条，且明显影响前方道路可视性
- **判"否"**：光线正常，无逆光/强反射，或仅有轻微侧光不影响视认

## 注意事项
- 隧道出口瞬间强光也算逆光，判"是"
- 短暂（<1秒）的光线变化若持续出现也算，判"是"
- 仅车辆或建筑的小范围反光不算，需影响道路可视性
- 夜间对向车灯眩光不在本任务范围内，判"否"

## 输出格式
纯净JSON（无markdown标记、无多余文字）：
{"result": "是/否", "reason": "简要描述判断依据，20字以内"}
