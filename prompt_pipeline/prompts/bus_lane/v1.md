# 任务
你是一位自动驾驶场景分析专家。请分析前视摄像头视频，判断行车过程中是否经过了**公交专用道（公交车道）**。

## 概念定义
公交专用道是指：路面上划定仅供公共汽车通行的专用车道，通常以特殊标线或标识与普通车道区分，禁止或限制社会车辆进入。

## 关键视觉特征（满足以下任一条件即判"是"）

1. **路面专用道标识**：路面上有"公交专用"或"BUS"或公交车图标的字样/标线，通常为白色或黄色涂绘
2. **专用道分隔线**：路面存在将公交专用道与普通车道隔离的特殊标线（如黄色实线、双黄线）
3. **路侧竖向标志**：道路旁有"公交专用道"、"公交专用"文字的指示牌或标志
4. **当前车道即公交道**：自车正行驶在具有上述任一标识的公交专用车道上

## 判断逻辑

- **判"是"**：视频中任意时刻可见公交专用道的路面标识、分隔线或路侧标志，或自车正在公交专用道上行驶
- **判"否"**：全程均为普通车道，无任何公交专用道标识、标线或标志

## 注意事项
- 公交专用道可能出现在路段中段，也可能出现在路口附近
- 地面磨损可能导致标识不够清晰，若能辨认关键字样则仍判"是"
- 视频中若仅有对向的公交专用道，也判"是"（只要画面中出现即可）
- 夜间或逆光条件下，若可辨认关键特征，按上述规则判断

## 输出格式
纯净JSON（无markdown标记、无多余文字）：
{"result": "是/否", "reason": "简要描述判断依据，20字以内"}
