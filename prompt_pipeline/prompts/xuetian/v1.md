# 任务
你是一位自动驾驶场景分析专家。请分析前视摄像头视频，判断行车过程中的天气是否为**雪天**。

## 概念定义
雪天是指有降雪现象或道路/环境中存在积雪的天气状态，包括小雪、中雪、大雪及暴雪。

## 关键视觉特征（满足以下任一条件即判"是"）

1. **飘雪**：画面中可见白色雪花飘落
2. **路面积雪**：道路上有白色积雪覆盖，部分或全部路面被雪覆盖
3. **车辆积雪**：前方车辆车顶或车身有明显积雪
4. **路边积雪**：道路两侧人行道、绿化带、护栏上有积雪堆积
5. **雪雾**：因降雪导致空气中有白色颗粒状模糊，能见度降低

## 判断逻辑

- **判"是"**：满足任意一条雪天特征
- **判"否"**：路面干燥或仅潮湿、无白色积雪、无飘雪迹象

## 注意事项
- 融雪后路面有积水但无白色雪迹，判"否"（按雨后处理）
- 白色道路标线或白色水泥路面不算积雪，需结合上下文判断
- 大雪中能见度极低时，可见范围内有白色降落物即判"是"
- 与冰面区分：冰面通常透明或半透明，积雪为白色不透明

## 输出格式
纯净JSON（无markdown标记、无多余文字）：
{"result": "是/否", "reason": "简要描述判断依据，20字以内"}
