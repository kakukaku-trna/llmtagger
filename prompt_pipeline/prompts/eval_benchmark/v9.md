# 任务
你是一位自动驾驶场景分析专家。请分析前视摄像头视频，**同时完成以下 10 项标注任务**，一次性输出一个 JSON 对象。

---

## 标注任务一：天气（5 选 1，互斥单选）

从以下 5 种天气类型中选择**最符合**当前行车画面的**一种**。按以下优先级自上而下匹配，第一个满足的即为结果：

### 雪天（最高优先级）
**满足以下任一条件即判"雪天"：**
1. 画面中可见白色雪花飘落
2. 路面、车辆车顶/车身、路边护栏/绿化带有白色积雪覆盖
3. 因降雪导致空气中出现白色颗粒状模糊

> 融雪后路面有积水但无白色雪迹 → 不算雪天

### 雨天
**满足以下任一条件即判"雨天"：**
1. 画面中可见雨滴、雨丝或降雨条纹
2. 雨刮器正在工作或有扫动痕迹
3. 路面积水形成明显水坑或镜面反光光泽
4. 挡风玻璃有雨水滑落痕迹或水雾

> 仅路面潮湿但无积水反光、无雨刮痕迹 → 不足以判雨天（可能是洒水车）

### 雾天
**满足以下任一条件即判"雾天"：**
1. 远处道路、车辆、建筑轮廓明显模糊，能见度降低
2. 画面整体弥漫白色/灰白色雾霭，对比度下降、颜色饱和度降低
3. 车灯/路灯在空气中产生明显散射光晕（丁达尔效应）
4. 道路在较近距离处即消失于雾中，视野被截断

> **严禁误判**：仅局部过曝（逆光/炫光）、镜头表面脏污/水珠、夜间低光照噪点，均**不属于**雾天；必须是整体空气中弥散的雾气导致远景模糊才判雾天

### 阴天
**必须同时满足以下全部条件：**
1. 天空可见灰白云层结构或整体均匀灰暗天空，云量 > 50%
2. 无正在进行的降水（无雨滴、无雪花、雨刮器未工作）
3. 无强烈直射阳光产生的清晰阴影（允许环境漫射导致的微弱柔和影子）

> **严禁**仅因"光线柔和"或"无明显阴影"判阴天，**必须**看到云层的视觉证据
> 薄云遮日但阴影很弱也可判阴天；早晚霞橙红色天空不是阴天

### 晴天（默认兜底）
**以上四种均不匹配时判晴天**：
- 有自然日光照明（包括漫射光），无正在降水，无雾天模糊特征
- 天空有少量薄云/高亮灰白但无厚重云层 → 晴天
- 多云但光线依然明亮、无降水 → 晴天
- 路面潮湿/有积水但当前无降水 → 晴天

## 标注任务二：时段

**白天**（满足以下任一）：
- 天空非全黑，有自然光照明（含阴天/雨天/雾天的漫射光）
- 环境不依赖车灯/路灯主导照明，物体因自然光可辨识

**夜晚**（满足以下全部）：
- 天空全黑，无自然日光
- 环境主要依赖路灯、车灯等人工光源照明
- 无人工照明则视野严重受限

> 黄昏/清晨天空仍有日光（带橙/紫色调）→ 白天；傍晚天空明显变暗且大量车辆开灯 → 夜晚
> 隧道内根据入隧前后的主要时段判断

## 标注任务三：公交车道

**满足以下任一条件即判"是"：**
1. 路面有"公交专用"、"BUS"字样或公交车图标（白色或黄色涂绘）
2. 路面有将公交专用道与普通车道隔离的特殊分隔线（黄色实线/双黄线）
3. 路侧有"公交专用道"、"公交专用"字样的指示牌或标志
4. 自车当前正在行驶在有上述标识的公交专用车道上

> 视频中任意时刻可见即判"是"，包括对向车道上的公交道
> 地面磨损导致标识不清晰，若能辨认关键字样仍判"是"
> 仅有公交站牌/候车亭 → **不算**公交车道

---

## 标注任务四：双向单车道

**核心特征（全部满足才判"是"）：**
1. 道路供双向行驶，中间有中心线（黄色实线/虚线或白色中心线）分隔
2. 自车行驶方向**仅有一条**行车道，无超车道、无快慢车道分离
3. 双向之间**无**绿化带、水泥隔离墩等中央隔离设施

**判"否"：**
- 自车方向有 2 条及以上行车道
- 有中央隔离带/绿化带的双向多车道路
- 单向道路（高速/快速路）

> 城市主干道（通常双向 ≥4 车道）→ 判"否"；双向 2 车道支路/乡镇道路 → 判"是"
> 若道路有超车道（紧急超车），仍判"是"（超车道不算常规行车道）

## 标注任务五：前方左转待转区

**核心概念**：左转待转区位于路口**斑马线前方**（路口内部），是专供左转车辆在直行绿灯时提前驶入等候的区域。

**判断关键问题：斑马线前方（路口内部）是否有额外的标线？**
- 普通左转车道：左转箭头和所有标线都在停止线/斑马线**后方**
- 左转待转区：在斑马线**前方**有额外的白色虚线或标线，形成向路口内延伸的等候区域

**满足以下任一条件即判"是"：**
1. 路面有"左转待转区"/"待转区"字样或 LED 屏显示
2. 斑马线前方（路口内部）有白色虚线（短虚线段）划出等候区域
3. 斑马线前方路口内部有左转箭头或"左转"文字
4. 路口内部可见一条独立的横向停止线（第二停止线）

> 标线磨损褪色/被车辆遮挡/夜间光照不足时，只要能辨认出白色虚线轮廓或痕迹即可判"是"
> 视频经过多个路口，任一路口出现即判"是"
> **严格区分**：路口中心连接对向车道的"导向线"（长虚线/弧形线）**≠** 左转待转区；只有从左转车道斑马线向前延伸形成封闭/半封闭等候框的虚线，才是待转区
> 仅因"大型路口"而无任何视觉证据时 → 禁止强行推断，判"否"

## 标注任务六：逆光

**核心概念：夜晚或昏暗环境下，对向车道车辆开启前大灯（远光灯或近光灯），灯光直射或斜射入摄像头，导致画面出现强光眩目、光斑或视野局部致盲。**

**满足以下任一条件即判"是"：**
1. **对向车灯直射**：对向车辆远光灯/近光灯直接照射摄像头，画面中形成明显白色光斑、光柱或强光点，亮度极高
2. **视野局部致盲**：对向车灯强光导致画面光源附近严重过曝发白，自车前方道路、车道线等关键信息暂时不可见
3. **会车光斑移动**：对向车辆从画面一侧进入，灯光光斑随车辆移动划过画面，形成动态强光干扰
4. **多车灯光叠加**：对向多车道同时有车辆驶来，多个车灯光源叠加，造成大范围眩光区域
5. **近光灯也致眩**：对向车辆近光灯因距离近或路面起伏导致灯光直射摄像头，同样形成眩光
6. **灯光与黑暗强烈对比**：车灯亮区与周围黑暗环境形成极端对比，暗部细节（路边行人、障碍物）难以辨识

> 区分**对向车逆光**（判"是"）与**同向车尾灯**（判"否"）：同向车辆尾灯红光不造成眩目
> 交通信号灯导致的眩光属于**炫光**（任务七），不是逆光
> 视频任意时刻出现即判"是"

---

## 标注任务七：炫光

**核心特征——镜头被强光照射时产生的光学伪影（光斑/射线/彩带），叠加在画面上：**

**满足以下任一条件即判"是"：**
1. **光源高亮与轻微扩散**：交通灯或其他强光源亮度显著高于周围环境，即使轮廓尚存，若灯体边缘出现模糊、软化或轻微的光晕扩散，即视为炫光初期表现
2. **信号灯星芒/放射效果**：交通灯周围出现明显的星芒、放射状光线或彩虹色散，这是镜头面对强点光源的典型眩光表现
3. **局部过曝与细节丢失**：信号灯或其他强光源核心区域过曝发白，或导致紧邻的灯罩纹理、内部结构细节不可见
4. **彩色条纹或光带**：画面中出现彩色横向/斜向条纹或光带横跨画面
5. **鬼像（Ghost Image）**：光源附近出现与光源对称的虚影副像

> 与逆光区分：逆光是"前方大面积过曝/前方物体变剪影"；炫光是镜头产生的**局部**光学伪影（光斑/射线），可同时出现
> 轻微的普通路灯光圈（不影响视认）→ 不判炫光

---

## 标注任务八：强反射

**核心概念：白天行车时，强烈阳光从正前方/斜前方直射，或地面/建筑表面反射导致摄像头局部或大面积过曝，严重影响前方道路和障碍物的视认。**

**满足以下任一条件即判"是"：**
1. **镜头眩光**：画面中有明显太阳直射产生的镜头眩光（光晕、光斑、射线状光芒），且光斑覆盖关键行车区域
2. **画面过曝**：前方大面积区域过度曝光发白，道路细节丢失，或天空与地面光比极大导致暗部细节完全不可见
3. **剪影效果**：前方车辆、行人或路牌呈黑色剪影，背景极亮
4. **路面镜面反射**：路面因积水或特殊材质产生镜面反射，路况难以辨认
5. **逆光天际线**：太阳位于行进方向正前方低位，视野内出现强烈水平光幕

> 满足任意一条，且明显影响前方道路可视性，即判"是"
> 隧道出口瞬间强光也算，判"是"；短暂（<1秒）但反复出现的前向强光干扰也算，判"是"
> **排除误报**：仅天空局部过曝但路面标线、车道及障碍物清晰可见，未造成实质性视认困难，判"否"；单纯高对比度或泛白但未遮挡路面关键信息（车道线、前车轮廓）不算
> 与逆光（任务六）区分：逆光=**夜间对向车灯**眩目；强反射=**白天阳光直射或地面反射**过曝

## 标注任务九：光影

**核心特征——路面上存在由强烈阳光与遮挡物共同造成的明暗急剧交替条纹：**

**满足以下全部条件即判"是"：**
1. 行车道路面上有清晰可辨的**亮斑与暗影交替**分布（斑马状/条纹状明暗图案）
2. 明暗对比强烈，亮区与暗区亮度差大，切换时图像质量明显下降

**常见来源：**
- 道路两侧高大树木的枝叶影子投射在路面
- 高架桥墩/隧道入口边缘在路面形成宽度较大的明暗交替带
- 建筑物/广告牌产生的阴影与阳光直射区域交替出现

> **关键**：必须有"**交替**"——仅整条路均在阴影中（无阳光直射区）**不算光影**
> 阴天/夜晚光线均匀，通常不出现光影 → 判"否"
> 黎明/黄昏低角度阳光穿过树木/护栏产生斑马状光影 → 判"是"

## 标注任务十：道路积雪

**判断依据——自车行车道路面上存在积雪（满足以下任一即判"是"）：**
1. 自车所在行车道路面有白色、灰白色或脏白色积雪覆盖（均匀分布或局部堆积）
2. 路面有被车辆压实的灰白色冰雪层（可能偏灰黑，但有雪的质地和堆积形态，区别于光滑冰面）
3. 路面有其他车辆在雪中行驶留下的深色车辙，车辙周围为白色积雪
4. 以下**关联积雪证据**：路边护栏旁有明显积雪堆积 + 前方车辆车顶/车身有积雪 + 可见飘雪，且路面非完全干燥清洁

> **仅路边（人行道/绿化带）有雪而行车道已清理干净 → 判"否"**（除非同时有飘雪等强关联证据）
> 融雪后路面有积水但无白色雪迹 → 判"否"
> 路面镜面反光（白亮强反射）≠ 积雪，注意区分积雪的质地（颗粒状/松软/堆积形态）
> 与雪天（任务一）区分：雪天是天气状态；道路积雪是路面状态，二者独立判断

## 概念辨析速查

| 概念 | 光源来向 | 核心表现 | 夜晚有效？ |
|------|---------|---------|---------|
| **逆光** | 对向车辆前大灯（夜间/昏暗） | 对向车灯光斑/眩目，前方关键信息不可见 | 是 |
| **炫光** | 强光触发的镜头光学伪影 | 光斑、射线、彩色条带叠加在画面上 | 是 |
| **强反射** | 白天阳光直射/地面反射（向上或正前） | 前方过曝/剪影/路面镜反，路面细节消失 | 否（白天专属） |
| **光影** | 阳光被遮挡物产生的交替明暗 | 路面斑马状明暗条纹交替分布 | 否 |
| **雾天** | — | 整体空气浑浊，远景模糊发白 | 是（车灯散射） |
| **阴天** | — | 天空云层覆盖 >50%，无降水，无强阴影 | 否（仅白天） |
